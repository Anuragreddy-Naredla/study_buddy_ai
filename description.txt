WHY GITOPS AND WHAT IS GITOPS?
Lets take there are 2pipelines which are Normal Pipeline and GitOps Pipeline and also have 3stages Codecheckout, Build & Push and Deploy stage
Normal Pipeline:
=> In Normal Pipeline 1st time we builded the pipeline Successfully but in the 2nd time my 3rd stage fails.So our app will fail completely here.
GitOps Pipeline:
=> In GitOps pipeline 1st time we builded the pipeline Successfully after bulding Successfully we will record this as a commit git but at the 
   2nd time my 3rd stage fails so with the help of ArgoCD it will rollback with the Successfully runned pipeline due to this my app will not stop
   working here.

A. Development and setup
Project and API setup->Configuration code->Question Schemas Models Code->Prompt Templates Code->Groq Client Setup Code->Question Generator Code->Helper Class Code
B. Application

C. Versioning and Containerization

Project and API setup=>create the Virtual environment and install necessary libraries and project structure
Configuration code=>setup the models from Groq or Openai etc...
Question Schemas Models Code=>relates to Pydantic for datamodels how the output should like
Prompt Templates Code=>Instructions given to LLM how the LLM model should behave
Groq Client Setup Code=>related to groq api we will create the temp which are arguments to LLM
Question Generator Code=>Logic for generating the question
Helper Class Code=>which are utilities functions inside our application code
Main Application=>create the main functions in helper class code then integrate in the main application code
Code Versioning=>keeps track record of commits and code changes etc...
DockerFile=>conatin the logic for Containerization
kubernetes Manifest Files=>conatins 2 things service file and deployment file
GCP VM Instance Setup=>install 3things which are Docker Engine, Minikube(for installation of minikube we require docker Engine) and Kubectl(to interact with the kubernetes cluster we need this)
jenkins setup=>setup for jenkins in VM
Github Integration with jenkins=>takes the latest code
Build and Push Docker image=>bulding and pushing the docker image to DockerHub
ArgoCD Setup=>installing the argocd and setup
Webhooks Github=>Whenever we build the pipeline we have to come to jenkins dashboard then wewill click on blue button to run the application this will be done automatically with the webhook
